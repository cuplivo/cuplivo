这一版定下的

  • 没有 tool call：生成和正文同时发生，模型不必等结果，也不用被再调用一次。
  • 位置天然正确：标记落在哪，图就长在哪；不需要把工具调用序号映射成消息位置。
  • 任何 provider 都能用：不依赖工具协议，纯 chat 的模型也能配图。
  • UI 与 A 共用：解析成功后是同一个图片块、同一行 (6.0s)、同一个 ⋯ 面板。
  • 来历靠语法：图位是文本解析出来的；「这条路径是承诺的吗」只能靠标记格式的约定。

必须接受的代价

  • 提示词塞进标记：括号、引号、竖线、CJK 换行都要处理；模型写歪就是一个解析不出来的标记。
  • 流式遮蔽：标记是一段普通文本，生成途中会一个字一个字到达，必须吞掉半个标记，否则用户会看见语法。
  • 导出 / 复制 / 搜索都要剥标记；解析失败还得有兜底 —— 显示原文（难看）还是整段吞掉（图就没了）。
  • 模型得靠提示词学会这个语法；每加一个参数（比例、质量、参考图），提示词和解析器一起长。
