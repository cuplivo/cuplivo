这一版定下的

  • 每个助手一处配置：provider + model，可覆盖全局。
  • 未选时回落到全局，「跟随默认模型」写明当前实际值。
  • 第一版就带上比例，按助手记。

必须接受的代价

  • 两个层级：助手 → 全局。用户很难一眼确定「这张图到底是哪个模型画的」，除非每处都显示实际值。
  • 助手编辑页多一段，设置面变大；每个新助手都要做一次选择（或依赖回落）。
  • 工具与后端要多读一层配置，测试也要覆盖两条路径。

分水岭：B 是「先建两层」，A 是「先一层，需要时再加一层」。加一层不破坏已有配置；拆一层会。

共用：工具拿到的都是一个 provider + model；第一版只接 /images/generations 形状的端点。注意：「未选回落到全局」本身也要实现，等于 A 的一层加上 B 的覆盖。
