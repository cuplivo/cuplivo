怎么进、怎么退

  • composer 的「绘图」chip 就是入口；开着的对话一眼能看到用哪个模型。
  • 点 chip → 抽屉：模型（跟随助手 / 指定）与比例；点「模型」进同一个模型选择器。
  • 抽屉里的「这个对话不再用」= 本对话关掉该工具；助手级的开在编辑助手。
  • 子代理用同一张抽屉、同一个选择器，标题变「子代理」、模型变「委托目标」。

这一版定下的

  • job 基建按 kind + model 建模：kind = image / delegate，model 由配置解析 —— 子代理复用同一套状态机。
  • 助手能选委托模型：无论委托给通用 subagent 还是给绘图，都是「这一行 + 下一级选模型」。

绘图默认仍是关；chip 只在开着时出现，关着时不占 composer 空间。

还没做：模型选择器的具体长相（复用聊天的模型选择页）；比例选项表。已定：入口在 composer、下一级是抽屉、job 按 kind + model 复用。
