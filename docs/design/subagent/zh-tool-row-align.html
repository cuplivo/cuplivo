跟着一起变的地方

  1. 两个 id 一起写。主行切换走一个 choke point（delegate + await_job），不再用只写单个 id 的 setLocalToolEnabled——否则工具面板的「已开 N 个」计数会和实际下发的工具对不上。
  2. 手机副行加 AnimatedSize，照绘图行的样子收放，不再是一段突然出现/消失。
  3. 注释与文档同轮改掉。subagent_config_sheet.dart 开头、chat_tools_sheet.dart 的「Both open the three-row dialog; neither is a switch.」、tools_popover.dart 里描述这个决定的注释，现在都在说相反的话。
  4. 提权行只在第一层出现。从子代理会话打开的配置不显示它（第 2 层起的委派不提供提权选项）。
