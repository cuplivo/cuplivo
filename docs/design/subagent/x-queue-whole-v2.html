规则

  • 完成即入队，队列里是整条结果（分隔线 + 续写），按完成时间 FIFO。
  • 不阻拦：应用在后台、你在打字，都照样入队并调度。唯一不许动的是你的草稿——入队、发送、清空都不碰它。
  • 一条一条落：上一轮结束才落下一轮，不合并。
  • 取消丢掉整条：结果行也不会出现，只能在子会话里看到。
  • 队列从「一格」扩成列表，用户手动排入的消息和子代理结果共用同一条队列、同一个顺序。
