预览选区：先做到复制

给预览套上 AppSelectionArea，获得复制、复制 Markdown、复制富文本、全选；不做翻译。

渲染效果区：可选中

周会结论：下周把导出流程拆成预览与捕获两种模式，再补一条真实渲染器的集成测试。

复制复制 Markdown复制富文本全选

与工作区 Markdown 预览一致：文字可选、可复制、可全选；不引入消息上下文。

为什么这样改

  • 预览区现在没有 SelectionArea，所以 Markdown 的 RichText 是纯文本，不能选。
  • 工作区的 Markdown 预览已经用 AppSelectionArea 做到这一点，是现成先例。
  • AppSelectionArea 的翻译项依赖 ChatMessage；预览没有消息，桌面端不会出现翻译。
代价：满足复制，不满足“翻译”；后续要翻译还得再接一条无消息的路径。
