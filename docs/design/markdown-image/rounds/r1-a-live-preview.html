导出的 PNG 里画的是这个失败卡，而不是一段让人以为“本来就只有代码”的源码块。

为什么这样改

  • 捕获模式（ExportCaptureScope）下图表块从不自己渲染，只读 MermaidImageCache；没热就退化成普通代码块。
  • 缓存由离屏 WebView 预热；工具的单测注入了假渲染器，真实桌面桥在这条路径上没有覆盖。
  • 聊天路径本来就有加载 / 失败态；预览借用同一套状态，失败才可见、可重试。
代价：需要先把桌面离屏渲染桥定位并验证（真实渲染器测试）；Linux 仍无 WebView，只能走失败卡。
