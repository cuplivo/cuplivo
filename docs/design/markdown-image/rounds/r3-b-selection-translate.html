翻译使用设置里的翻译模型（没有消息/会话可依赖时回退到翻译工具），结果仍按应用现有的翻译面板展示。

没有消息时怎么办

聊天消息的翻译入口要求 ChatMessage 来解析模型和会话；预览没有消息。两条可行路径：读设置里的翻译模型，或打开翻译工具并带入选中文本。

为什么这样改

  • 需求明确包含翻译；只做复制会让预览的选区能力停在半路。
  • 现有翻译面板依赖 ChatMessage；预览需要一条无消息的模型解析或“带入翻译工具”的回退。
  • 复制仍是主路径，翻译是增量动作，不影响选区本身。
代价：需要新增无消息的翻译入口（模型解析或翻译工具跳转），并处理没有配置翻译模型时的错误提示。
