为什么这样改

  • 用户要的 1:1 与工具的“预览就是文件”原则同时成立。
  • 宽度取面板宽度并夹在 480–720，窄窗口不会导出过窄的图。
  • 代价是导出文件宽度随窗口/分栏变化，同一文档在不同窗口会得到不同宽度的 PNG。
代价：文件宽度不再固定；收起源码、拖窗口都会改变下一次导出的尺寸；需要把宽度显示出来。
