### 🔗 兼容性

Cuplivo 是 Kelivo 的一个社区分支，具有强兼容性：

- 备份 zip 格式完整兼容。配置 WebDAV 或 S3（或本地导出 / 导入），恢复从 Kelivo 导出的备份文件即可无缝接续，无需重新配置。
- 已更改包名，以避免冲突。许多开发者可能担心自己改的代码实装后与后续 Kelivo 更新冲突；但安装 Cuplivo **无需卸载、不会覆盖** Kelivo，数据安全双重保障。
- 有真实用户实测。目前已知作者本人和至少 5 位稳定用户在使用，未遇到问题。
- 界面风格继承 Kelivo。整体无大幅改动，原有用户可以快速适应。

#### 🧪 稳定性

本 Fork 的定位是"新功能试验场"，可能会添加一些社区认为有用的新功能，大多依赖简易自测，以期为追求新功能的用户提供更加开箱即用的服务。追求基本的可用性和稳定性（无 P0 Bug，目前暂未遇到过数据损坏/无法开启软件的恶性 Bug），但版本发布更加频繁，审查宽松一些，使用新功能可能出现一些 P1/P2 Level Bug，但反馈会得到及时处理。

我们注意到主仓库 Kelivo 正在进行大规模数据存储的重构。本仓库近期计划仅限兼容其导出的新版 zip。为了数据完整性做出的大多防御性变更未必会被采纳，敬请做好备份。

### ✨ 新功能

Cuplivo 与大多数个人定制 / 单功能 Fork 不同，旨在添加多特性以供更广大的受众尝鲜。随着上游（Kelivo）添加对应功能后，部分项目可能会被移除。

#### 备份同步功能增强

1. **增量备份 & 局域网同步** — 仅上传自某个选定日期以来的对话和消息，以及附件等；在局域网下快捷同步两台设备的状态。
   - 实测：一次 12.6 MB 的完整备份后，通常仅会产生 50 KB 至 1.5 MB 的增量上传。随着附件和图片的积累，节省效果会更加明显。这降低了带宽与存储开销，也有助于养成更频繁的备份习惯。
   - 注意：仍建议定期进行完整快照备份。

2. **删除恢复（回收站）** — 删除的对话进入回收站，可配置容量上限（默认 10 KB），防止误删；同步时携带删除标记，一端删除的内容会在另一端及时清除 (#137)。

3. **从 RikkaHub 导入** — 通过迁移网站将 RikkaHub 备份转换为 Cuplivo 兼容的备份，再通过"备份文件导入"导入即可 (#165)。

#### 提升对话体验的招牌能力

1. **Proactive care（Ta的来信）** — AI 可按设定时间主动向用户发送关怀消息（仅 Android）。
   - 仅 Android：后台闹钟 + 通知渠道，闹钟在强制停止后可恢复
   - *提示*：在助手设置的"Ta的来信"标签页中开启

2. **多助手群聊** — 导演模型编排的群聊：后台导演模型决定由哪位助手发言，成员在共享对话中聊天，各自持有私有上下文 (#150)。

3. **内置文件系统 MCP** — 通过内存 MCP 服务器读、写、正则查找本地文件；支持挂载本地目录，无需命令行，安全性优先；挂载后可在应用内文件浏览器中浏览，grep 搜索结果支持分页与上下文，支持查看代码架构（`kelivo_outline`）、下载互联网资源至工作区，长网页支持工作区缓存续读 (#173, #221, #222)。

4. **多 AI 横向对比** — 选择 2 个及以上模型同时回答，在同一界面横向对比回复。择优采用，也可将多份回复总结、融合或评论合成为一个回复（类似更自由的 OpenRouter Fusion）。
   - 桌面端现在每页显示 2 个模型回复，采用双列布局。
   - *提示*：在模型选择器中多选模型后发送消息即可激活

5. **记忆模式切换 + 时间注入** — 每助手独立开关，保持系统提示词稳定以提升 API 缓存命中：记忆可在**自动注入**（每次对话自动注入记忆到系统提示词）与**按需工具**（通过 `read_memory` 工具按需读取记忆）间切换；时间注入在每条用户消息后追加缓存友好的时间戳，而非写入系统提示词。开启时间注入时，智能警告对话框会扫描系统提示词与记忆提示词中的易变变量 (#121)。
   - *提示*：为获得最佳缓存性能，建议关闭"最近对话参考"，切换到按需记忆模式并开启时间注入。

#### Agent 能力初步增强

1. **子代理委派 (Handoff)** — 通过 MCP 工具将子任务委派给其他助手执行（即发即忘）。真正可返回结果的子代理计划在后续版本实现 (#140)。

2. **技能 (Skills)** — 从公开 GitHub 仓库导入技能，并提供辅助文件工具。技能持久化存储在文件系统中，并包含在备份中。v3 新增分类、总开关与对话级技能入口，增强入口可发现性、优化选择体验 (#161)。

#### API 调控能力增强

1. **OAuth 账户登录** — Grok xAI (#164) 与 OpenAI Codex (#157) 支持设备码登录；MCP 支持 OAuth v2 自动流程：授权服务器发现、动态客户端注册与回环回调 (#156)。

2. **搜索多 Key 轮换** — 为搜索服务配置多个 API Key，遇到限流自动轮换，提升有效限额 (#139)。

3. **MCP 工具结果图回传** — 将 MCP 工具返回的图片回传给 LLM 供应商，让模型能看到工具输出 (#159)。

4. **供应商级自定义 Headers/Body** — 每个供应商可附加自定义请求头与请求体字段 (#120)。

5. **每助手 OCR 模式** — 新增"智能" OCR 模式：模型有视觉能力时关闭 OCR，无视觉能力时开启 OCR；每助手可选自动/始终/关闭 (#171)。

6. **每服务器心跳间隔** — 为每个 MCP 服务器单独配置心跳间隔，避免 429 限流 (#108)。

7. **PDF/Office 文件附件** — 支持直接上传 PDF、Word、Excel、PowerPoint 文档作为附件，并提供文档处理配置选项。

8. **Thinking 开关** — 每助手独立开关，控制 summary/suggestion/compress/translate/OCR 模型的 thinking (#117)。

#### 实用能力增强

1. **手动"保留最近 N 条"压缩 + 提示词预设** — 压缩对话时可仅保留最近 N 条消息，实时预览 Token 估算（默认保留条数随对话规模自动调整），提升角色扮演、小说写作等体验，减少风格偏移；内置压缩/OCR 提示词预设，支持快速切换 (#143, #236)。

2. **对话侧边栏批量操作** — 在侧边栏中批量选择、删除或移动多个对话，提升对话管理效率 (#82)。

3. **存储空间管理** — 按时间或大小排序已存储文件，查找未被引用的图片/文件（孤儿），反向定位已存储文件属于哪条聊天记录 (#128)。

4. **TTS 音频：保存到本地 + 朗读选中文本** — 在浮窗播放器中保存云端生成的 TTS 音频至本地文件 (#131)；右键/长按选中的助手消息文本可朗读 (#130)。

5. **增强助手消息直接复制** — 朴素子序列 Markdown 复制 + 引用，快速提取消息内容 (#122)。

6. **多类别请求日志** — 请求日志现在覆盖 MCP、TTS、搜索服务，各自分类独立、开关与历史互不影响 (#162)。

#### 界面渲染功能增强

1. **阅读模式** — 较长的助手回答可开启阅读模式，降低阅读疲劳 (#160)。

2. **SVG 预览** — 在 `svg` 代码块内联渲染 SVG 图表。

3. **自定义动态主题色** — 通过色相拾取器选择自定义种子色，完全控制应用 accent 颜色 (#107)。

4. **美化请求日志** — 在日志查看器中拆分消息与配置，让请求体中的消息轮次更易读 (#127)。

5. **桌面端 Markdown 表格工具栏** — 桌面端表格工具栏支持多格式复制（纯文本、HTML、LaTeX）(#109)。

6. **预设消息** — 预设消息在聊天列表中折叠到切换栏后；仅存在预设消息时阻止新建对话 (#116)。

#### 其他修复

- **停止按钮强制断流** — 修复自上游 Kelivo v1.1.6 起的长期问题：点击"停止"从未真正断开 TCP 连接，供应商无法收到取消通知，导致后台静默生成和意外的 Token 消耗/多扣费
- **跨 MCP 同名工具冲突** — 已修复：当多个 MCP 服务器暴露同名工具时，现在会检测并解决冲突（禁用或重命名），而非导致工具调用歧义
- Gemini 缓存 Token 的准确统计
- 优化标题生成逻辑（首次失败自动重试）
- 修复大尺寸 base64 图片导致正则表达式栈溢出的问题
- Markdown 数学公式渲染：支持列表下的多行公式，支持 `\tag` 渲染 (#227)
- 修复 Windows 上 Win+V 剪贴板历史粘贴（Flutter 引擎 Bug 绕过）
- 图片分享：导出图片强制 8 位 sRGB 读回，修复自 v1.1.16 以来 iOS 表格底色异常的问题 (#193)
- iOS：存储空间管理现在会统计并清理真实的 iOS tmp 目录 (#223)
- 其他多项稳定性改进

## ✨ 功能特性

- 🎨 **现代化设计** - Material You 设计语言，支持动态主题色(Android12+)
- 🌙 **深色模式** - 完美适配深色主题，保护您的眼睛
- 🌍 **多语言支持** - 支持中文和英文界面
- 🖥️ **多平台支持** - 移动端与桌面端均支持（Android/iOS/Harmony、Windows/macOS/Linux）
- 🔄 **多供应商支持** - 支持 OpenAI、Google Gemini、Anthropic 等主流 AI 供应商
- 🤖 **自定义助手** - 创建和管理个性化 AI 助手
- 🖼️ **多模态输入** - 支持图片、文本文档、PDF、Word 文档等多种格式
- 📝 **Markdown 渲染** - 完整支持代码高亮、LaTeX 公式、表格等
- 🎙️ **语音服务** - 内置系统 TTS，同时支持 OpenAI / Google Gemini / ElevenLabs 语音服务器
- 🛠️ **MCP 支持** - Model Context Protocol 工具集成
- 🧰 **内置 MCP 工具** - 内置 fetch MCP 工具
- 🔍 **网络搜索** - 集成多种搜索引擎（Bing、DuckDuckGo、Exa、Tavily、智谱、LinkUp、Brave、Metaso、SearXNG、Ollama、Jina、Perplexity、Bocha、Serper、Grok）
- 🧩 **提示词变量** - 支持模型名称、时间等动态变量
- 📤 **二维码分享** - 通过二维码导出和导入供应商配置
- 💾 **数据备份** - 支持聊天记录备份和恢复
- 🌐 **自定义请求** - 支持自定义 HTTP 请求头和请求体
- 🔡 **自定义字体** - 支持自定义字体（系统字体 / Google Fonts）
- ⚙️ **Android 后台生成对话** - 可在后台持续生成消息（可在设置中开启）。
