这一版定下的

  • 工具读一处配置：全局绘图模型；换成别的模型只改这里。
  • 复用已有的「默认模型」页，不新增设置入口。
  • 未配置时工具不出现在助手的工具列表里，不会调出一个没配好的工具。

必须接受的代价

  • 所有助手共用一个绘图模型；写实助手和插画助手没法各用各的，要等后续加 override。
  • 聊天中改不了模型，得回设置页。

分水岭：先一个全局值，工具只读一处；以后要按助手覆盖，是在它上面加一层，不是推倒重来。

共用：无论放在哪，工具拿到的都是一个 provider + model（type=image）；第一版只有这一个来源。另一个变体：每个助手单独选，未选时回落到全局。
