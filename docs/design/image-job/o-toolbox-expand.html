三态怎么走

状态手机桌面
关一行，无子行一行，detail 常显，无勾
开 · 已配行 + 子行「模型 · X ›」一行，detail「X ›」+ 勾
开 · 未配行 + 子行「未配置 · 去选择 ›」detail「未配置 ›」+ 勾

交互

  • 点开关/勾 = 开或关；开启的瞬间若未配置，直接展开子行，不弹单独对话框。
  • 点子行 / detail = 进模型选择页（和聊天同一个选择器）。
  • 关掉：子行收起，高度回到一行；已选的模型记住，下次开直接用。

代价

  • 手机收起时看不到模型，得开一次；桌面常显，不占额外高度。
  • 开启与配置是两步（开 → 选），不能一键开；这换来的是"不会静默开一个画不了图的工具"。

这一版定下的：主行只放开关/勾与名字；配置是开启后长出来的子行（手机），或 detail（桌面）；开而未配时子行/ detail 显示「未配置 · 去选择」。
