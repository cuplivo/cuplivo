「模型」进的是和聊天同一个模型选择页；选完这一行就变成显式值，下一级不再显示「跟随」。

为什么这样摆

  • 一行说清三件事：叫什么、现在用什么、开没开。开关右侧的 › 是唯一入口，不和学习成本打架。
  • 关着也能点进去配置 —— 配好了再开，不用先开再配。
  • 子代理与绘图是同一套「行 + 下一级」，子代理的下一级只是换了字段名。

代价

  • 工具箱列表会变长；每加一个 job 类工具就多一行。
  • 开关与 › 挨得近，误触开关会改上下文（点行本身不切换，只有开关切换）。

这一版定下的：工具箱一行 = 名称 + 当前值 + 开关 + ›；› 进下一级，下一级就是「模型 / 比例」这类少量字段。 已定：job 按 kind + model 建模，绘图与子代理共用。
