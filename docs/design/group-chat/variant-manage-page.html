助手与群聊，同一份顺序

现在有两份排位：侧栏按“助手和群聊混排”拖，设置里的助手页按“只有助手”拖，两边各写各的， 拖完就对不上。这一轮把管理页和侧栏收成一份顺序，并且把“新建助手”和“新建群聊”放在同一个入口。

A · 一张列表，一个 +

助手与群聊同列，拖动就是全局顺序（侧栏立刻同步）。行样式按类型分：助手给出提示词首行， 群聊给出成员名单。右上角一个 + 展开“新建助手 / 新建群聊”。

A 放弃的东西

  • 群聊卡和助手卡共用一种排版，群聊没法显示“话题数”这类只属于它的信息
  • 侧栏的标签分组在管理页里只剩行内一枚小标签，不再是分组标题
  • 助手自己那份排序字段退场，没有“只重排助手”的旋钮了

B 放弃的东西

  • 跨类型拖动做不到：想把群聊挪到某个助手前面，只能回侧栏拖
  • 多了一个“当前在哪一段”的状态，新建后还要决定跳不跳段
  • 顺序仍然只有一份，但“段”会让它看起来像两份
