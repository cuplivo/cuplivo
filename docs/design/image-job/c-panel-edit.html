重新生成 编辑提示词 仅保存
霓虹雨夜的旧书店，湿漉漉的招牌映在水洼里，赛博朋克风格插画
1点卡头或 ⋯ 开面板。生成中是 取消；完成是 编辑；失败是 重试，编辑同样可用。
2点 编辑：升起「编辑提示词」抽屉，输入框里是原提示词，改完两个出口。
3仅保存：只更新提示词，图不动；下次重新生成才用它。和消息编辑的「保存」同一种后果。
4重新生成：同一张卡片回到生成中，新图到达后替换；旧图在新图到达前仍然显示。

抽屉沿用 message_edit_sheet 的骨架：标题居中、左右两个动作、DraggableScrollableSheet + 键盘安全。桌面端换成对话框（仓库规则：桌面不用 bottom sheet）。

为什么编辑不做成两个按钮

  • 面板上只有 编辑；重新生成 只在抽屉里，和改提示词是同一个动作的两条出口 —— 不会有人在没看见提示词的情况下重画。
  • 复制留在提示词旁边（一次性动作），取消只在生成中出现，重试只在失败时出现。面板宽度不随状态变。

必须接受的代价

  • 「仅保存」会让提示词和这张图暂时对不上，卡片上没有角标提示 —— 和消息编辑的「保存」一样，靠下一次重新生成收口。
  • 抽屉是拖拽高度 + 键盘安全，比面板多一层状态；桌面端还要单独做对话框版本。
  • token 统计得等适配器报告 usage：按 token 的模型给 tokens，按张的只给张数，缺了就只能显示「—」。

这一版定下的：卡头一行 生成插图 (12.6s) ⋯；面板里用量复用消息 token 统计的样式与气泡；编辑只有一个入口，出口是「仅保存 / 重新生成」。统计仍只记卡片这一行，不进统计页 —— kelivo#1492 要新增 usage_events 账本表，那是 schema 6 的事。还没定：重新生成要不要像消息那样留版本（旧图可回看），等这版跑通再单独定。
